# 0.2.1 登录页渲染修复

日期：2026-09-16。仅涉及客户端，不需要修改或重新部署服务端。

## 复现与修复

- 回归测试确认原中文占位符输出 NUL 字符；40×18 终端的登录页高达 21 行，超过可显示高度。
- 改为按显示宽度渲染中文占位符，不再混用字符数和列宽；密钥掩码输入不变。
- 小窗口使用紧凑登录页，焦点切换不增加页面高度，保留昵称和单个密钥输入框。

## 验证

- go test ./... -count=1、go vet ./... 通过。
- 24×10、40×18、80×20、100×30 登录页边界与回车切换回归测试通过。
- 实际 Windows 0.2.1 EXE 在 100×30、40×18 ConPTY 中完成：昵称输入、回车后等待光标刷新、密钥输入、中文发送、调整窗口与退出。
- 验证终端输出无 NUL 字符、无明文密钥。
