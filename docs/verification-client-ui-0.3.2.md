# 客户端 0.3.2 界面修复验收

日期：2026-09-17。

## 修复内容

- 登录页昵称与房间口令增加间隔，换房窗口字段同样分隔。
- Windows 输出启用 VT 与延迟自动换行，并在退出时还原输出模式；表单预留右侧宽度，避免边框满列折行造成局部重绘残留。
- 换房快捷键由 Ctrl+R 改为 F2，原生按键映射、界面提示和测试同步修改。Esc 取消，Enter 确认。

## 复现与验证

- 用原 0.3.1 exe 在隐藏传统 Windows 控制台复现两个“房间口令”标签；新增控制台缓冲区读取测试，不只检查 View 字符串。
- 0.3.2 通过传统控制台测试：标签不重复，表单每行边框完整；输入中文昵称、Enter 切换焦点、输入口令后显示正常且口令不明文展示。
- 发布 exe 通过 Windows ConPTY 100×30、60×20、40×18 测试，包括缩至 24×10 后恢复、光标闪烁、中文登录、多行消息、F2 打开换房、Esc 取消及成功换房。
- go test ./... 通过；go vet ./... 通过。
- 设置 XCHAT_EXE 为发布 exe 后，go test ./internal/tui -run 'TestLegacyConsoleLogin|TestWindowsExecutableInPseudoTerminal' -count=1 -v 通过。

## 发布范围

仅构建客户端 exe、Windows 客户端 zip 和源码 zip，版本为 0.3.2；保留旧发布包。不部署、停止或重启任何服务端。终端集成测试使用本地隔离测试服务，不操作线上聊天数据。

历史 0.3.1 验收中的 Ctrl+R 已由本版本 F2 替代。
