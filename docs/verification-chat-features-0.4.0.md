# 0.4.0 功能验收

基线：`origin/main`。开发分支：`codex/chat-recall-tls-mentions-kaomoji`。没有合并或取用颜文字开发分支，目录、加载逻辑和客户端选择器已重新实现。

## 已实现

- 本人消息两分钟内撤回：随机客户端凭证的哈希作为归属信息，存入加密消息正文，不在消息广播中公开。服务端按归属和时间验证。相同昵称、新进程或其他房间不能认领消息。
- 撤回事务替换正文、移除 @名单并更新本房间同步代次。在线通知在历史补齐完成后按顺序交付；离线客户端重连时重载历史，避免保留原文。旧记录无需消息表结构迁移。
- 原生 WSS：服务端证书与私钥参数、环境变量和安装脚本；客户端系统 CA、自定义 CA 与构建时内置公共 CA；最低 TLS 1.2，校验证书链、有效期和主机名，拒绝重定向。远程明文默认拒绝。
- @成员：当前房间成员选择、搜索、输入 @ 触发；复杂昵称用 JSON 引用格式；服务端识别、去重并加密存储名单；本人被提及的消息带标记和提示。
- 颜文字：服务端可配置 JSON 目录（初始 10 分类、72 项），客户端通过加密 GET 获取并缓存，配置热更新无需重新编译；中文与英文关键词搜索、分类与分页；光标插入、完整长度检查、Ctrl+S 单独发送并保留草稿；可选客户端本地 JSON 覆盖。
- Windows 原生 F3/F4/F5 按键映射，以及换房时证书信任和客户端身份的延续。

## 行为边界

撤回身份只存在于当前客户端进程，重连和换房会保留，退出进程后丢失。旧版消息没有归属信息，不可撤回。TLS 保护客户端到服务端的链路，服务端仍能解密内容。撤回是逻辑替换，无法回收他人已复制的内容或清理旧备份。
