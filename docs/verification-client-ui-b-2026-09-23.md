# B 方案深色紧凑界面验收

日期：2026-09-23。

## 界面调整

- 使用炭黑底、灰白正文、青色昵称、绿色本人昵称和暖黄色提醒；程序自行绘制背景，适配已有黑底控制台。
- 消息区域足够宽时，将时间、昵称、正文排成三列；中文长消息和多行消息的续行与正文对齐。窄窗口恢复上下排列。
- 日期独立分隔。保留历史分页、@你 标记、撤回状态和发送异常提示。
- 90 列及以上显示右侧成员栏，列表超出高度时显示剩余人数；输入区与聊天区等宽。
- 登录、换房、颜文字、成员和撤回选择窗口使用同一套深色样式。登录和换房表单在宽窗口居中。
- 统一显示 SpaceChat 品牌；新增草稿字符计数。保留原有快捷键和网络行为。
- Windows Terminal 打包配置使用相同配色。应用界面右侧预留两列，避免传统控制台对部分字符的宽度判断触发自动换行。

## 验证

- `go test ./internal/tui ./internal/terminal -count=1` 通过。
- 新增界面测试覆盖 24×10、35×15、60×20、89×24、90×10、100×30、140×40；在最终裁剪前检查输入区、成员栏和消息区域的尺寸。
- 验证中文换行后的正文完整、窗口缩放不丢草稿，以及各页面每个可见字符和空白单元格都有背景颜色。
- `go vet ./...` 通过。
- 编译后的 Windows 客户端通过传统控制台登录测试，含中文输入、光标闪烁、字段位置稳定和口令遮蔽。
- 编译后的 Windows 客户端通过 100×30、60×20、40×18 ConPTY 测试，含缩小至 24×10 后恢复、中文与多行发送、F2 换房、颜文字、草稿保留、撤回和 @成员。
- 检查了实际 Go 界面输出的 100×30 聊天、40×18 聊天和登录渲染图，使用示例消息。

## 全量测试的既有失败

`go test ./... -count=1` 在当前 Windows 环境未全部通过。以下失败均在未改动的 HEAD 源码副本中复现：

- `cmd/xchat` 的安装配置隔离测试读取到本机已安装的服务地址。
- `cmd/xchat-server` 和 `internal/securestore` 的密钥创建测试在同步 Windows 目录时返回 Access is denied。
- `internal/server` 的 Linux 首装脚本测试缺少 `sh`。
- `internal/update` 的 Linux 路径、可执行权限及更新集成测试与当前 Windows 环境不兼容或受到本机配置影响。

本次仅修改客户端界面和对应终端配色，没有发布在线更新或替换已有安装。
