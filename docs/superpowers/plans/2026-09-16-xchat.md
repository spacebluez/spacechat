# XChat Implementation Plan

说明：实际主机、地址及环境标识已脱敏；示例值仅用于说明，不可直接用于生产部署。

> **For agentic workers:** Use executing-plans to implement task-by-task in this session. No subagents or Git commits without authorization.

**Goal:** 交付完整 Go 源码、Windows x64 TUI 客户端，在 目标服务器 部署持久化聊天室。

**Architecture:** 协议和 SQLite 存储独立；服务端串行化保存和广播，有界队列隔离慢用户。客户端网络处理重连，Bubble Tea 处理 UI。

**Tech Stack:** Go 1.26、coder/websocket、modernc SQLite、Bubble Tea v1 组件系列。

## Global Constraints
- 单公共聊天室，无认证；在线昵称唯一，1–20 字符。
- 正文最多 2,000 字符，拒绝控制字符；分页最多 100 条。
- 保存后广播；结果未知不重发；按 ID 补齐。
- Windows amd64 客户端；目标服务器 为 Linux amd64/systemd。
- 当前仓库工作，不新建分支、不提交；交付源码及测试。
