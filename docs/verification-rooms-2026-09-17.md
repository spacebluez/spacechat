# 多房间版本验收（2026-09-17）

实际主机、地址、口令及环境标识不进入仓库。本记录只描述功能与结果。

## 交付范围
- 新分支 codex/multi-room-encryption，基于既有功能分支，不修改 main 或旧功能分支。
- 任意非空口令自动创建房间；同口令同房间，跨房间允许相同昵称。
- AES-256-GCM 加密昵称及正文；房间索引用独立派生密钥的 HMAC-SHA256；随机主密钥只在服务器受限配置目录。
- Enter 发送，Windows 原生 Shift+Enter 换行，Ctrl+J 兼容换行；Ctrl+V 整体粘贴并规范化 CRLF。
- 每天北京时间 00:00 清空全部新房间及历史；Python 手动脚本使用相同接口。

## 操作与限制
- 推荐使用客户端 Ctrl+V 粘贴多行。部分外层终端会将右键粘贴的 CR 转换为 Enter，本期不将这种无法区分的输入承诺为安全粘贴。
- 数据库加密不是端到端加密，也不加密 ws 链路；弱口令可能被猜测，部署在可信内网或使用 TLS 代理。
- 清理为逻辑删除，不保证物理擦除；主密钥需单独安全备份。
- Windows 桌面实际输入法组合、外层终端快捷键覆盖仍需使用者验收；自动测试不等同于覆盖所有终端环境。
